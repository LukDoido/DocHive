What it does

Three things, done properly.

Reads and files

Each document is read for the parties, the dates, the amounts, the notice period. From that comes a name and a destination, built from the naming rules you already use.

Watches your dates

The review step

Nothing moves until you approve it.

Proposals wait in a queue. You approve, edit or reject. Only on approval is a file renamed and moved, and only into folders that already exist.

Every action is logged

Who approved what, when, and what the file was called before.

Undo in one click

Any move can be reversed to the exact name and location it came from.

Corrections are kept

When you fix a proposal, that correction feeds the next one of its kind.
